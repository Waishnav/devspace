## Now — v1.1

A coding harness over MCP that gives ChatGPT and Claude the tools each model
knows, with activity history you can browse at `/web`. Subagents across seven
harnesses — plus any ACP agent — from any shell or bot, with worktree
isolation for parallel writers, cancellation, and normalized turn events.

**Experimental:** dynamic workflows — replayable scripts that fan out,
pipeline, and phase agent calls — behind `DEVSPACE_EXPERIMENTAL_WORKFLOWS=1`.

## Next

- Dynamic workflows out of experimental.
- Richer provider observability: best-effort token counts per call.

## Later — environments

Today, DevSpace orchestrates agents on _your_ machine. The longer-term
direction is **environments**: a dedicated computer and compute for your
agents, so a workflow can keep running, in parallel and in isolation, while
your laptop is closed.

The bet underneath all of it: you will stop deciding what to prompt next. A
model will translate intent into work and route each piece to the best harness
for it. DevSpace is the agent-agnostic layer that makes that routing possible.
