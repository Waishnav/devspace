---
title: Native file download
description: Save a file attached or generated by the MCP host directly into an open workspace, safely.
---

With `artifacts.enabled: true`, hosts such as ChatGPT can save a native
attached or generated file — an image, a CSV, a PDF — into an open workspace.

```txt
open_workspace
  -> download_artifact({ file, workspace_id, path })
  -> { path }
```

```txt
download_artifact({
  file: <native file value supplied by the MCP host>,
  workspace_id: "ws_123",
  path: "public/images/generated-image.png"
})
```

DevSpace creates missing parent directories and refuses to overwrite an
existing file. Afterwards, ordinary tools can inspect, move, or replace it.

## Safety

- Only the host's native file object is accepted — no pasted URLs or local
  source paths.
- Trusted OpenAI download hosts and redirects only.
- Absolute paths, traversal, symlinked parents, and existing destinations fail
  closed.
- Streams under `artifacts.maxFileBytes` and publishes without overwrite.
- Available on Linux, macOS, and Windows using descriptor- or handle-anchored
  filesystem operations. Not registered on BSD.
- Content is never extracted or executed, and file values are never logged.
